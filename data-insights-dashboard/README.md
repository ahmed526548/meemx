# DataPulse — Interactive Analytics Dashboard

A responsive Arabic RTL business intelligence dashboard built with vanilla HTML, CSS, and JavaScript. It presents sample e-commerce performance data in a clean, modern interface.

## Features
- KPI cards for revenue, orders, average order value, and conversion rate.
- Interactive 7-day, 30-day, and 90-day reporting periods.
- Dynamic SVG sales chart.
- Traffic-source breakdown and regional performance bars.
- Best-selling products table.
- Export the currently selected report as CSV.
- Responsive layout for desktop, tablet, and mobile.
- Arabic RTL layout with accessible labels and semantic HTML.

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

- HTML5
- CSS3
- Vanilla JavaScript
- SVG chart rendering
- Google Fonts (Cairo)

## Data note
All displayed figures are fictional sample data created for demonstration and portfolio purposes. The dashboard is a frontend prototype; it is not connected to a live store, analytics provider, or backend database.
